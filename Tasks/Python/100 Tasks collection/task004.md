Write a method which can calculate square value of number

<br><br>

### RU
***
Напишите метод, который вычисляет квадрат числа

<br><br>

<details>
<summary>Solution/Решение</summary>

```python
def square(num):
    return num ** 2

print(square(2))
print(square(3))
```
