### Question 62 | Level 1

### EN
***
Write a program to read an ASCII string and to convert it to a unicode string encoded by utf-8.

<br><br>

### RU
***
Напишите программу для чтения ASCII-строки и преобразования ее в юникод-строку, закодированную в utf-8.

<br><br>

<details>
<summary>Solution/Решение</summary>

```python
s = input()
u = unicode(s, "utf-8")
print(u)
```

</details>
